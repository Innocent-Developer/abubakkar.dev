⌁ backend_decisions // Frameworks, data and reliability

Node.js and TypeScript

Express services and TypeScript application code support product APIs, webhook handlers and real-time workflows. My Node.js development page explains deliverables, while the REST API guide covers contracts and status codes.

Python framework choices

FastAPI appears in API Test Lab and other portfolio work. Django offers an integrated ORM, admin and application framework; Flask offers a smaller HTTP foundation. These are architectural alternatives to evaluate against a project’s needs, rather than interchangeable claims of project experience.

PostgreSQL and database design

My published PostgreSQL tenancy guide explains composite keys, transaction scope and row security. SQL, MongoDB and Redis solve different problems: constraints and relationships, document workflows, and short-lived cache or coordination state. The portfolio identifies the database used by each project.

Testing and operation

Request validation, authorization checks, integration tests and production logs connect these tools into a service that can be maintained. Read the backend learning and deployment guide and Node.js security checklist for the engineering decisions behind the technology names.
